## 3 · Infection risk model

| Metric (5-fold, grouped by wound) | Value |
|---|---:|
| precision | 0.9943 |
| recall | 0.9830 |
| f1 | 0.9885 |
| auc | 0.9951 |
| avg_precision | 0.9993 |

**These are proxy-label numbers and must always be quoted as such.** No public dataset labels a wound as infected, so the target is wound tissue (1) versus intact skin (0). A feature ablation in the full report shows four colour-variance features alone reach the same F1 as all thirty: the model separates classes by *visual heterogeneity*, not by erythema. Early phlebitis is the opposite profile — uniformly slightly red intact skin — so this score does not evidence clinical capability.

External check on 21 IV-relevant Medetec images (extravasation injuries): **100% detection**, mean risk 0.993. Every image there is abnormal, so this is recall with no negative class — and those injuries are severe, established damage rather than the early signal the system targets.

See [`infection_risk_model_report.md`](infection_risk_model_report.md).

## 4 · Temporal validation

No public longitudinal IV-site dataset exists — no dataset photographs the same site on consecutive days. The alert thresholds (risk > 0.6, delta > 0.15, three consecutive increases) are the values specified in the project plan, **never fitted to outcome data**. Their false-alarm and missed-detection rates are unmeasured.

## Limitations

1. **NIR training, RGB deployment.** The vein model is trained on near-infrared imagery because every public vein dataset with masks is NIR. Deploying against an ordinary RGB camera is an unmeasured domain shift, and no public RGB vein dataset with masks exists to measure it.

2. **Paediatric training cohort.** CUBITAL is 1,008 subjects aged 5–22 (median 11), 97% recorded as slim, 42 obese. The clinical need is in elderly, obese and dehydrated adults, where veins are hardest to find. Transfer to that population is untested and must not be assumed.

3. **Proxy infection labels.** No dataset labels an IV site as infected. The risk model learns wound-versus-skin, and the ablation shows it keys on heterogeneity rather than redness.

4. **No cannula-detection data.** Phase 4 is scaffolding only.

5. **No longitudinal data.** The temporal tracker's thresholds are unvalidated.

6. **Under-trained vein model.** The current checkpoint is epoch 6 of a planned 25, stopped when the machine exhausted swap. Validation Dice was still climbing, so the reported figures are a lower bound.

7. **Known failure mode.** The vein model produces predictions on background linen, and can place an insertion marker off the patient. The fix — using CUBITAL's arm class, which the loader currently discards — is identified but not yet implemented.

## What would make this clinically credible

- An IRB-approved prospective collection of IV sites photographed daily, with clinician-assessed phlebitis grading. That single dataset would replace the proxy labels, provide real longitudinal validation, and supply the cannula-detection images.
- An adult cohort for the vein module, spanning body habitus and skin tone.
- A formal validation study before any clinical use.
